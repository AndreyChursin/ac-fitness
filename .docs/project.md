# Описание проекта

[Содержание](index.md)

## Назначение

Train With Andrey — публичный лендинг образовательного наставничества по
тренировочным привычкам, регулярности и основам питания. Пользователь знакомится
с подходом, форматами сопровождения и автором, читает FAQ и переходит по контактной
ссылке. Контент подчёркивает личный опыт автора и не позиционирует услугу как
медицинскую помощь или индивидуальное назначение нагрузок и лечебного питания.

Русский и английский варианты используют одинаковую разметку и отдельные словари.
Текущие основные адреса — `/ru` и `/en`.

## Форматы сопровождения

| Позиция | Формат | Цена EUR | Альтернатива USDT | Период |
| --- | --- | --- | --- | --- |
| 0 | Разговор по делу / A useful conversation | €15 | 15 USDT | 30 минут |
| 1 | Basic Mentor | €29 | 30 USDT | Месяц |
| 2 | Personal Mentor | €59 | 60 USDT | Месяц |

Цены и выделение карточки задаются в `src/i18n/plans.ts`; названия, периоды и
наполнение — в словарях. Цены EUR и USDT фиксированы отдельно, без пересчёта по курсу. Это витрина услуг: кнопки не создают заказ или подписку.

## Технологии

Версии приведены по `package.json`; точные разрешённые зависимости — в lockfile.

| Технология | Версия / настройка | Назначение |
| --- | --- | --- |
| Next.js | 16.4.2, App Router | Маршрутизация, рендеринг, SEO |
| React / React DOM | 19.3.0 | Компоненты интерфейса |
| TypeScript | `^5`, strict | Статическая типизация |
| Tailwind CSS | `^4` | CSS-инструментарий; основное оформление написано обычным CSS |
| Vercel Analytics | `^1.6.1` | Компонент аналитики в layout |
| ESLint | `^9`, Next.js presets | Проверка исходников |
| pnpm | 10.32.1 | Зависимости и команды проекта |

Включены `cacheComponents`, `partialPrefetching` и `reactCompiler`.
Для установленной версии Next.js ориентируйся на локальные руководства в
`node_modules/next/dist/docs/`.

## Границы текущей реализации

- Нет API приложения, базы данных, авторизации, административной панели или CMS.
- Нет формы отправки сообщений, оплаты, бронирования и управления подписками.
- Нет автоматического определения языка браузера и сохранения выбора в cookie.
- Нет собственного sitemap, robots, Open Graph изображения и системы pluralization.
- Нет подключённого постоянного браузерного тестового набора; Playwright не входит
  в зависимости проекта.
- Контакт без настройки окружения остаётся заглушкой `https://t.me/`.
- Год в footer задан строкой `2026`; он не обновляется автоматически.

Эти пункты описывают состояние проекта, а не обязательный план дальнейшей работы.
