# Устранение ошибок

[Содержание](index.md)

## `page.tsx doesn't have a root layout`

Проверь дерево App Router. Корневой layout находится в
`src/app/[locale]/layout.tsx`; страницы внутри этого дерева его наследуют.
Случайный `src/app/page.tsx` находится снаружи и не получает этот layout.

Не добавляй дублирующий layout только для подавления ошибки. Сначала определи
назначение страницы и помести её в правильное дерево. Переход с `/` уже
обрабатывается `src/proxy.ts`.

## Русский открывается первым

Причина — `defaultLocale = 'ru'` и перенаправление с `/`, а не порядок файлов.
Для изменения языка корня обнови `defaultLocale` в `src/i18n/config.ts` и проверь
redirect и `x-default`. `/ru` и `/en` остаются явным выбором языка.

## Новый язык возвращает 404

Проверь `locales`, загрузчик словаря и проверку `isLocale`. Полная процедура —
[добавление языка](localization.md#добавление-языка). Одного нового JSON недостаточно.
Произвольные вложенные страницы тоже возвращают 404, пока для них нет `page.tsx`.

## Ошибка `check:i18n`

В сообщении указан путь вроде `messages.header.home` или `messages.services.cards`.
Проверь наличие ключей, тип, длину массива и непустую строку в обоих JSON.
Английский словарь задаёт эталон структуры. Не отключай проверку в build для
пропуска незавершённого перевода.

## `PageProps` или `LayoutProps` не найдены

После чистой установки выполни:

```sh
pnpm exec next typegen
pnpm exec tsc --noEmit
```

Проверь, что `tsconfig.json` включает `.next/types/**/*.ts` и
`.next/dev/types/**/*.ts`. Не создавай собственные глобальные заглушки типов и
не коммить `.next`.

## Canonical ведёт на localhost или другой домен

Проверь окружение во время сборки. Приоритет: `SITE_URL` →
`VERCEL_PROJECT_PRODUCTION_URL` → `http://localhost:3000`. Установи SITE_URL с
правильной схемой и пересобери приложение. Порт `pnpm start --port ...` не меняет
metadataBase автоматически.

## Контакт ведёт на общую страницу Telegram

Не задан `NEXT_PUBLIC_CONTACT_URL`; `https://t.me/` — существующая заглушка.
Задай полный контактный URL до сборки и пересобери. Надпись о необходимости
настроить контакт должна исчезнуть.

## Перевод карточки получил неверную цену

Карточки связаны по индексу `services.cards[i]` ↔ `plans[i]`. Проверь порядок
и длину в обоих словарях и `src/i18n/plans.ts`. Проверка словарей не сравнивает
их с числовыми данными тарифов.

## Переключатель теряет query или якорь

Обычный клик после гидратации добавляет `window.location.search` и `hash`.
Проверь ошибки JavaScript и воспроизведи сценарий из [verification.md](verification.md).
При отключённом JavaScript, открытии из контекстного меню или средней кнопкой
сохранение этих частей URL текущей реализацией не гарантируется.

## Шапка выходит за экран

Проверь обе локали и медиаправила `.site-header` / `.header-actions` / `.site-nav`
в `globals.css`. На мобильном текст контакта скрыт, остаётся иконка; меню языка
тоже сокращается. Не решай проблему удалением доступных подписей или уменьшением
всех touch targets.

## Установка сообщает о рассогласованном lockfile

Сверь `package.json` и `pnpm-lock.yaml`, версию pnpm и историю изменений.
При намеренном изменении зависимостей обнови lockfile через `pnpm install`
и проверь diff. Для воспроизводимой чистой установки используй frozen-lockfile.

## Браузерный инструмент не запускается

В проекте нет Playwright dependency и настроенного E2E runner. Внешнему инструменту
нужны совместимый браузер и его системные библиотеки; наличие browser cache
недостаточно. Ошибка запуска Chromium не означает ошибку приложения. Отдельно
выполни доступные HTTP-проверки и честно укажи, что браузерный сценарий не проверен.
