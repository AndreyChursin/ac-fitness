# Интерфейс и оформление

[Содержание](index.md)

## Компоненты

`src/app/[locale]/page.tsx` содержит общий лендинг. Секции привязаны к стабильным
ID: `top`, `approach`, `services`, `about`, `faq`, `contact`. Эти ID используются
кнопками и шапкой; сохраняй их либо обновляй все ссылки одновременно.

`SiteHeader` отвечает за логотип, навигацию по секциям, языковое меню и внешний
контакт. Логотип ведёт на `/{locale}#top`. Контакт в шапке открывается с
`target="_blank"` и `rel="noopener noreferrer"`; нижний CTA использует обычную ссылку.

Шапка остаётся в потоке документа и закрепляется у верхней границы viewport при\nпрокрутке (`position: sticky; top: 0; z-index: 100`), а не через `position: fixed`.\nЕё полупрозрачный фон, blur, световые блики и fallback для браузеров без\n`backdrop-filter` реализованы в CSS Module. Учитывай, что sticky может перестать\nработать при добавлении `overflow: hidden/auto` к предкам.\n\nЯкорная навигация должна оставлять заголовки секций видимыми под шапкой:\n`html { scroll-padding-top: 100px }`, а при ширине до 600 px — `78px`.\nСохраняй эти адаптивные отступы при изменении высоты шапки и проверяй\nпереходы по `#approach`, `#services`, `#about`, `#faq` и `#contact`.\n\n`LanguageSwitcher` отвечает только за выбор языка. Меню и FAQ используют нативные
`details` / `summary`; отдельной библиотеки раскрывающихся элементов нет.

## CSS

Всё оформление расположено в `src/app/globals.css`, подключённом из root layout.
Файл импортирует `tailwindcss`, но текущие компоненты в основном используют
собственные CSS-классы. Значительная часть исходного CSS компактно записана в
длинные строки; это текущее состояние, а не требование продолжать такой стиль.

| Переменная | Значение | Назначение |
| --- | --- | --- |
| `--bg` | `#101410` | Основной фон |
| `--fg` | `#f4f2e9` | Основной текст |
| `--muted` | `#adb7a9` | Вторичный текст |
| `--accent` | `#d7f37c` | Акцент и CTA |
| `--card` | `#1b221c` | Фон карточек |

Шрифт — стек `Inter, system-ui, -apple-system, sans-serif`; файл Inter или
`next/font` сейчас не подключены. Декоративная hero-графика выполнена CSS-градиентами,
текстом и псевдоэлементом, без загружаемого изображения. Иконки шапки — встроенные SVG.

Ключевые классы: `.wrap`, `.hero`, `.hero-art`, `.grid`, `.card`, `.featured`,
`.about`, `.faq`, `.cta`, `.site-header`, `.site-nav`, `.header-actions`,
`.language-menu`, `.language-options`, `.header-contact`.

## Адаптивность

| Условие | Поведение |
| --- | --- |
| Основная ширина | Контейнер до 1140 px, hero в две колонки, карточки в три |
| До 980 px | Скрывается `.site-nav` |
| До 760 px | Hero, карточки и about в одну колонку; footer вертикальный |
| До 600 px | Уменьшаются отступы и логотип; контакт становится кнопкой-иконкой |
| До 360 px | Дополнительное уменьшение логотипа и промежутков шапки |

На узком экране текст и стрелка текущего языка скрыты, но остаются значок и
доступное имя. Контактная кнопка сохраняет размер 44 × 44 px. Отдельного мобильного
меню навигации по секциям сейчас нет.

## Доступность и проверка изменений

- Переводи `aria-label` через `header` и `art`, не только видимые надписи.
- Сохраняй семантические `header`, `nav`, `main`, `section`, `article`, `footer`.
- Декоративные SVG имеют `aria-hidden`; графика hero имеет `role="img"` и описание.
- Выбранный язык отмечен `aria-current="page"`.
- Проверяй закрепление шапки при прокрутке, читаемость на фоне секций и\n  доступность языкового меню поверх содержимого.\n- Проверяй раскрытие меню и FAQ с клавиатуры, видимость фокуса и отсутствие
  горизонтального переполнения на обеих локалях.
- Проверяй длинный английский текст на узких экранах; сокращение русского текста
  не решает проблему ширины в другой локали.

В CSS включён плавный scroll и hover-transform кнопок. Отдельная обработка
`prefers-reduced-motion` сейчас отсутствует; аудит WCAG не выполняется автоматически.
