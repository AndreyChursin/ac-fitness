# Локализация и SEO

[Содержание](index.md)

## Источники данных

| Файл | Ответственность |
| --- | --- |
| `src/i18n/config.ts` | Поддерживаемые языки, тип Locale, язык по умолчанию, имена, Intl-локали и пути |
| `src/i18n/dictionaries.ts` | Тип Messages и динамические импорты словарей |
| `src/i18n/messages/en.json` | Английские тексты и эталон структуры |
| `src/i18n/messages/ru.json` | Русские тексты той же структуры |
| `src/i18n/plans.ts` | Числовые цены, featured и формат валюты |
| `scripts/check-translations.mjs` | Проверка обоих словарей |

`Messages` выводится из английского JSON. Загрузчики проверяются через
`satisfies Record<Locale, () => Promise<Messages>>`. TypeScript проверяет форму
данных, но не качество перевода и не все ограничения длины массивов.

## Разделы словаря

| Ключ | Данные |
| --- | --- |
| `nav` | Пять подписей: approach, services, about, faq, контакт |
| `eyebrow`, `hero`, `lead`, `actions` | Первый экран, три строки заголовка и две кнопки |
| `approach` | Философия; карточки как пары `[title, body]` |
| `services` | Заголовок, пояснение, карточки форматов и note |
| `about` | Заголовок, абзацы, цитата |
| `faq` | Заголовок и пары `[question, answer]` |
| `contact` | CTA и сообщение о ненастроенном контакте |
| `footer` | Нижняя подпись |
| `header` | Home, разделы, выбор языка, язык и контакт для доступности |
| `metadata` | SEO title и description |
| `art` | Доступное описание и три строки декоративной надписи |

Некоторые данные позиционные: не меняй порядок массивов только в одном языке.
Карточки `services.cards[i]` используют цену и featured из `plans[i]`.
Проверка словарей сравнивает массивы между языками, но не сверяет их с `plans`.
Синхронизируй все три места при добавлении или перестановке тарифов.

## Изменение текста

1. Найди соответствующий ключ в обоих JSON.
2. Обнови переводы с сохранением структуры.
3. При новом ключе используй его в общей странице или компоненте.
4. Выполни `pnpm check:i18n`, проверку типов и просмотри обе версии.

Не помещай HTML в JSON. Разметка, `<br />`, `<em>` и ссылки остаются в TSX.
Текущие словари — обычные строки и массивы; ICU-сообщения и pluralization не
подключены. Если они понадобятся, это отдельное изменение архитектуры.

## Выбор языка

Язык определяется URL. `/` перенаправляет на `defaultLocale = 'ru'`; заголовок
`Accept-Language`, cookie и localStorage сейчас не используются.

`localizePath` заменяет существующий поддерживаемый префикс или добавляет его.
Переключатель выводит названия языков на их собственном языке, `hrefLang`, `lang`
и `aria-current` для активной локали. При обычном клике обработчик добавляет
текущие query и hash: `/ru?source=test#faq` → `/en?source=test#faq`.

Без JavaScript ссылки на языковые страницы работают, но сохранение query/hash
обработчиком недоступно. Сохранение query/hash при открытии через контекстное меню
или среднюю кнопку отдельно не гарантируется текущей реализацией.

## Числа, валюта и даты

`plans.ts` хранит цены EUR `15`, `29`, `59` и отдельные фиксированные цены
USDT `15`, `30`, `60`. `formatPrice` использует `Intl.NumberFormat`, локали
`ru-RS` / `en-RS`, валюту EUR, символ валюты и отсутствие дробной части.
USDT отображается отдельной строкой с локализованным `services.usdtLabel`;
это не автоматическая конвертация по курсу. Переключение языка меняет
представление EUR, но не стоимость услуги. Не вставляй форматированную цену в словарь.

Дат в текущем контенте нет. При их добавлении используй `Intl.DateTimeFormat`
и явно выбери часовой пояс, соответствующий назначению даты.

## SEO

`generateMetadata` в `[locale]/layout.tsx` формирует:

- Переведённые title и description.
- Canonical `/{locale}`.
- Hreflang для каждой поддерживаемой локали.
- `x-default`, указывающий на `/{defaultLocale}`.
- Open Graph title, description, URL, siteName и type `website`.
- Open Graph locale `ru_RU` / `en_US` и альтернативную локаль.

Абсолютный origin определяется через `SITE_URL`, затем
`VERCEL_PROJECT_PRODUCTION_URL`, затем `http://localhost:3000`.
Перед production-сборкой задай корректный origin; см. [деплой](deployment.md).
Open Graph изображение, sitemap и robots сейчас не реализованы.

## Добавление языка

1. Добавь код в `locales` в `config.ts`.
2. Заполни `languageNames` и `intlLocales`; при необходимости измени defaultLocale.
3. Создай JSON с полным набором ключей и элементов английского словаря.
4. Добавь загрузчик в `dictionaries.ts`.
5. Расширь `check-translations.mjs`: сейчас он явно проверяет только EN и RU.
6. Обнови Open Graph locale/alternateLocale: сейчас там условие только RU/EN.
7. Проверь перевод всех текстов, включая доступность, метаданные и описание графики.
8. Выполни сборку и сценарии из [проверок](verification.md), обнови документацию.

`generateStaticParams`, hreflang и список языков меню используют `locales`, поэтому
не требуют отдельного списка маршрутов.
